# darshanhshah.com

Personal portfolio of Darshan Shah, controls engineer.

- `index.html`: homepage
- `st-practice.html`: Structured Text practice judge (40 Logix-style ST problems, runs in the browser)

Deploys automatically to Cloudflare Workers on every push to `main` (see `wrangler.jsonc`).

Branches other than `main` build a preview link without touching the live site.
