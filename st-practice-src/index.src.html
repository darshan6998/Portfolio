How grading works

  • Each test is a sequence of scans. Before every scan the inputs are written, then your whole routine runs once, top to bottom.
  • Every tag keeps its value between scans, just like controller tags. Internal tags start at 0 or FALSE.
  • Outputs are compared at each checkpoint row. REAL values must match within 0.001.
  • Run grades the example tests. Submit adds hidden tests, and a problem counts as solved only when they all pass.
  • Timers run on a simulated clock: ACC starts at 0 on the first enabled scan and adds the scan time on each scan after that.
  • Faults are simulated too: an array index out of range or a runaway loop stops the run, as a major fault would.

Supported syntax

  • :=, IF/ELSIF/ELSE, CASE … OF (ranges 1..5:), FOR … BY, WHILE, REPEAT, EXIT, RETURN
  • AND OR XOR NOT & (bitwise on integers), = <> < <= > >=, + - * / MOD **
  • Types: BOOL, SINT, INT, DINT, REAL, ARRAY, FBD_TIMER, FBD_ONESHOT, TIMER, COUNTER
  • Instructions: TONR, TOFR, OSRI, OSFI. Functions: ABS, SQRT/SQR, TRN, SIN, COS, TAN, LN, LOG. Like Studio 5000, there is no MIN, MAX or LIMIT, so clamp with IF
  • Bits: Word.5, Word.[i]. Literals: 16#FF, 2#1010, 1.5e3. Comments: //, (* *), /* */
  • Optional local tags at the top of a routine. This is a simulator convenience: in Studio 5000 you create tags in the tag editor.
VAR
  Count : DINT := 0;
  Buf   : ARRAY[0..4] OF REAL;
END_VAR

Ladder logic

  • Written as Studio 5000 rung text, one rung per line ending in ;. This is the same format as "Edit rung as text" and L5X exports. The diagram draws itself as you type.
  • Branches: BST XIC(A) NXB XIC(B) BND puts A and B in parallel.
  • Bits: XIC XIO OTE OTL OTU ONS OSR OSF. Timers and counters: TON TOF RTO CTU CTD RES, for example TON(T1,5000,0)
  • Compare: EQU NEQ GRT GEQ LES LEQ LIM CMP. Math and move: MOV ADD SUB MUL DIV MOD CPT CLR ABS
  • After a run, the power-flow view shows which contacts were energized on the last scan.
BST XIC(Start) NXB XIC(Motor) BND XIO(Stop) OTE(Motor);
XIC(Motor) TON(Run_Tmr,5000,0);

Editor keys

  • Ctrl/⌘ + Enter runs the examples. Ctrl/⌘ + Shift + Enter submits.
  • Tab indents by two spaces and Enter keeps the current indent. Press Esc, then Tab, to move focus out of the editor.
  • Your code and solved problems are kept in this browser.

This is a simulator for the common subset of Logix ST and ladder, not Studio 5000 itself. Use it to build fluency, then verify on real hardware.
